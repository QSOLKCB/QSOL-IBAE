# Contributing

Research discussion, bug reports, benchmark results, and reproducibility reports are welcome.

External code contributions are **not currently accepted** unless covered by a separate written contribution agreement with QSOL-IMC.

This restriction exists because QSOL-IBAE uses a custom source-available license with special commercial/productization rights for QSOL-IMC and OpenAI Parties. Accepting code without clear contribution rights could make future licensing ambiguous.

If you find a defect, please open an issue with:

- the invariant ID involved, if known;
- minimal reproduction steps;
- deterministic input fixtures where possible;
- expected and observed behavior;
- environment/version information.
